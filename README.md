# MYTOWN 直方

「直方のこと、これ1個見ればだいたい分かる。」を目指す、非公式の地域生活アプリMVPです。

## 現在の状態

2026年9月1日時点で、UIデモだけの状態から **直方市の実際の公開情報を表示するMVP** に切り替えています。

現在の主な実データ:

- 直方市コミュニティバスの2026年10月1日路線・時刻表変更
- 2027年4月小学校入学予定者向け就学時健康診断
- 2026年秋のピラティス教室募集
- 令和8年9月定例市議会の日程
- 令和8年のごみ・資源リサイクル収集案内
- 直方市の人口・世帯数
- 直方市公式サイトの新着・注目情報

すべて、直方市公式ページへのリンクを付けます。

## 自動同期

`.github/workflows/sync-nogata.yml` が GitHub Actions で約6時間ごとに実行されます。

同期処理は `scripts/sync_nogata.py` が担当し、結果を `data/latest.json` に書き込みます。

### 自動取得するもの

- 直方市公式サイトの新着RSS
- 直方市公式サイトの注目RSS
- ホームページ掲載の人口・世帯数
- 指定した重要ページの更新日確認

### 自動取得しすぎないもの

予算書、工事発注見通し、議案PDFなど、文書構造が複雑で誤読リスクが高いデータは、現時点では無理に自動要約しません。

このアプリでは「自動化率」より「誤情報を出さないこと」を優先します。

## 同期設計

1. GitHub Actions が定期実行
2. 直方市の一次情報だけを取得
3. `data/latest.json` を生成
4. JSONの妥当性を検証
5. 変更があればGitHubへ自動コミット
6. アプリは `data/latest.json` を `no-store` で取得
7. Service Workerも同期JSONだけは network-first で処理

同期に失敗した場合、推測した値を生成しません。取得できなかった情報源は失敗状態として記録し、前回確認済みデータを残します。

## 重要な注意

MYTOWNは **直方市公式アプリではありません**。

表示内容は直方市の公開情報を元に整理していますが、最終確認は必ずリンク先の直方市公式ページで行えるようにします。

特に災害・火災など緊急性の高い情報について、このアプリを唯一の情報源として利用する設計にはしていません。

## 画面

- `きょう` — 最新の生活情報・市議会・ごみ・人口・新着
- `場所` — 公式ページで住所まで確認できる情報だけを表示
- `見つける` — 普通の言葉やカテゴリから同期情報を検索
- `聞く` — 現在同期している公式情報だけを対象にした簡易質問UI
- 詳細 — `これ何？ → なんで？ → いくら？ → 誰が決めた？`

確認できない金額や意思決定経路は、推測せず「確認できない」と表示します。

## ファイル構成

- `index.html` — アプリシェル
- `styles.css` / `review-fixes.css` — UI
- `app.js` — 画面・検索・公式データ表示
- `data/latest.json` — 同期済み公開情報
- `scripts/sync_nogata.py` — データ同期
- `.github/workflows/sync-nogata.yml` — 定期実行
- `sw.js` — PWAキャッシュ（同期JSONはnetwork-first）
- `manifest.webmanifest` — PWA設定

## プロダクト原則

政治を前面に出さない。

生活を便利にする → 街について疑問を持つ → 理由・お金・決まり方が分かる → 結果として政治が身近になる、の順番を守ります。

# MYTOWN 直方 — MVP

「直方のこと、これ1個見ればだいたい分かる。」を目指す、**非公式**の地域生活アプリMVPです。直方市公式アプリではありません。

## 今回入っている体験

- `きょう` — 「今日の直方」ホーム。ごみ・イベント・制度など、まず生活に役立つ情報から入る
- `近く` — 「近くで何してる？」デモ地図。場所と結びつく情報だけを表示
- `見つける` — 「ゴミ」「子供のお金」「工事」など普通の言葉から探す入口
- `聞く` — 普通の日本語で質問する回答UIデモ
- 出来事詳細 — `これ何？ → なんで？ → いくら？ → 誰が決めた？`
- PWA対応 — 対応ブラウザではホーム画面追加が可能
- アクセシビリティ基礎対応 — フォーカス管理、選択状態、十分なタップ領域、色だけに依存しない状態表示

## 重要：現在はデモデータ

このMVPに表示される工事・イベント・制度・距離・期限は **UI/UX確認用のサンプル** です。実在の行政情報ではありません。

また、現在地を使っても実際の距離を計算できない段階なので、MVPでは位置情報の許可を求めません。

本番化では、直方市などの一次資料に接続し、次を徹底します。

1. 確認できた事実だけ表示する
2. 予算額・事業費・契約額を混同しない
3. 公開日・更新日・一次資料URL・最終確認日を持つ
4. 分からないことをAIで推測して補完しない
5. 市長・議員をAIが評価しない
6. 公式情報とアプリ側の要約を区別する
7. 古い情報を「現在の情報」のように見せない

## 2026-09-01 客観レビューで修正した点

- 「近く」画面から位置を持たない制度・意見募集を除外
- 地図フィルターと表示ピンを連動
- デモ距離 `350m` を廃止し、実距離と誤認しない表示へ変更
- 実際に使わない位置情報の許可要求を削除
- ホームにごみ情報のデモを追加し、生活アプリとしての価値を強化
- 「直方は何にお金を使ってる？」を子育て制度として誤分類する回答ロジックを修正
- 「ゴミ」「子供」など表記ゆれを検索できるよう改善
- 検索条件・選択状態・クリア操作を追加
- 詳細画面の「これ何？／なんで？／いくら？／誰が決めた？」に選択状態を追加
- 画面遷移時のフォーカス管理とブラウザ戻る操作を改善
- 外部データ接続を見据え、画面表示用文字列をエスケープ
- 通知デモを実際の通知と誤認しない文言へ変更
- PWAキャッシュを、更新が古いまま残りにくい方式へ変更
- サービスワーカーが将来の外部APIまで無差別にキャッシュしないよう同一オリジンに限定

## ローカルで確認

静的アプリなのでビルドは不要です。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## 構成

- `index.html` — アプリシェル
- `styles.css` — モバイルファーストUI
- `review-fixes.css` — 客観レビュー後のアクセシビリティ・操作性改善
- `app.js` — 画面遷移・デモデータ・検索・インタラクション
- `manifest.webmanifest` — PWA設定
- `sw.js` — オフライン用キャッシュと更新処理
- `icon.svg` — 仮アプリアイコン

## 次の段階

1. 直方市の公式データソース棚卸し
2. ごみ・イベントなど「毎週使う理由」になる生活情報から実データ化
3. 本物のホームフィードデータに差し替え
4. 工事・予算・議会を紐づけるデータ設計
5. 地図を実地理データへ置換
6. 市長・議員ページ追加
7. 意見募集・行政サービス追加
8. 公式資料根拠型AI検索を接続

## プロダクト原則

政治を前面に出さない。

**生活を便利にする → 街について疑問を持つ → 理由・お金・決まり方が分かる → 結果として政治が身近になる**

この順番を守ります。

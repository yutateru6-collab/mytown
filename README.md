# MYTOWN 直方 — MVP

「直方のこと、これ1個見ればだいたい分かる。」を目指す、地域生活アプリの最初のスマホ向けMVPです。

## 今回入っている体験

- `きょう` — 「今日の直方」ホーム
- `近く` — 「近くで何してる？」デモ地図
- `見つける` — 役所の正式名称を知らなくても探せる入口
- `聞く` — 普通の日本語で質問するUI
- 出来事詳細 — `これ何？ → なんで？ → いくら？ → 誰が決めた？`
- PWA対応 — 対応ブラウザではホーム画面追加が可能
- アクセシビリティ基礎対応 — フォーカス表示、十分なタップ領域、色だけに依存しない状態表示

## 重要：現在はデモデータ

このMVPに表示される工事・イベント・制度・金額・期限は **UI/UX確認用のサンプル** です。実在の行政情報ではありません。

本番化では、直方市などの一次資料に接続し、次を徹底します。

1. 確認できた事実だけ表示する
2. 予算額・事業費・契約額を混同しない
3. 公開日・更新日・一次資料URL・最終確認日を持つ
4. 分からないことをAIで推測して補完しない
5. 市長・議員をAIが評価しない

## ローカルで確認

静的アプリなのでビルドは不要です。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` を開いてください。

## 構成

- `index.html` — アプリシェル
- `styles.css` — モバイルファーストUI
- `app.js` — 画面遷移・デモデータ・インタラクション
- `manifest.webmanifest` — PWA設定
- `sw.js` — 基本キャッシュ
- `icon.svg` — 仮アプリアイコン

## 次の段階

1. 直方市の公式データソース棚卸し
2. 本物のホームフィードデータに差し替え
3. 工事・予算・議会を紐づけるデータ設計
4. 地図を実地理データへ置換
5. 市長・議員ページ追加
6. 意見募集・行政サービス追加
7. 公式資料根拠型AI検索を接続

## プロダクト原則

政治を前面に出さない。生活を便利にする → 街について疑問を持つ → 理由・お金・決まり方が分かる → 結果として政治が身近になる、の順番を守ります。

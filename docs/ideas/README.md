# MYTOWN 実装検討メモ

ここは、まだ実装すると決めていないアイデア・改善案・気づきを残すための置き場です。

## 使い方

今後、会話中に「これMYTOWNに入れたい」「あとで実装したい」「GitHubにメモしといて」などの案が出たら、原則としてここに記録します。

- すぐ実装するもの → Issue / 実装作業へ
- まだ検討段階のもの → `docs/ideas/` にメモ
- 調査が必要なもの → メモ内に「未確認事項」を明記
- 事実情報を含むもの → 出典・確認日を残す
- 政治・行政情報 → 推測と事実を必ず分離する

## ファイル名

`YYYY-MM-DD-短い英語名.md`

例：

- `2026-09-02-citizen-help-routing.md`
- `2026-09-10-roadwork-map.md`
- `2026-09-15-council-alerts.md`

## ステータス

各メモの冒頭に次のどれかを付けます。

- `idea`：思いつき・初期案
- `research`：調査中
- `candidate`：実装候補
- `planned`：実装予定
- `implemented`：実装済み
- `hold`：保留
- `rejected`：見送り

## 優先度

- `P0`：最優先。MYTOWNの核になる
- `P1`：重要。近いうちに検討
- `P2`：あると良い
- `P3`：アイデア保管

## 基本方針

MYTOWNの目的は、政治に詳しい人だけが使うアプリにしないこと。

**「便利だから使う → 自分の町の仕組みが自然に分かる」**

という流れを優先します。

新しい案を追加するときは、機能の面白さだけでなく、次の3点を必ず考えます。

1. 市民の日常の困りごとを本当に減らせるか
2. 初心者でも迷わず使えるか
3. 事実・出典・更新日を確認できる設計になっているか
